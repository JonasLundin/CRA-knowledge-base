# Summary

M/606 Line 19 requests a vertical European Standard on essential cybersecurity requirements for antivirus software and malware detection/quarantine tools under CRA Annex III Class I point 4[^m606].

# Legal effect

This request entry sets the standardisation mandate; presumption of conformity requires citation in the OJEU.

# Requested scope and mandate

- **Legal basis**: CRA Annex III, Class I, point 4.
- **Mandate objective**: Define requirements for secure signature updates, kernel/driver attack surface protection, self-defense against tampering, telemetry privacy, and false-positive handling.

# Responsible committee and deliverables

- **Technical Committee**: ETSI TC CYBER / WG EUSR (Rapporteur: Pol Alemany)[^stan4cra-etsi].
- **Deliverable**: `EN 304-619` (ETSI Work Item `REN/CYBER-00111`, WKI ID 74411)[^etsi-wi-74411].
