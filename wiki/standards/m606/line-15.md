# Summary

M/606 Line 15 requests a horizontal European Standard covering the full set of manufacturer vulnerability handling obligations set out in CRA Annex I, Part II[^m606].

# Legal effect

This request entry sets the standardisation mandate; presumption of conformity with Annex I Part II requirements arises only upon OJEU citation of the final harmonised standard.

# Requested scope and mandate

- **Legal basis**: CRA Annex I, Part II (points 1 to 8).
- **Mandate objective**: Establish standard processes for:
  1. Identifying and documenting vulnerabilities and components (Software Bill of Materials / SBOM in machine-readable format);
  2. Addressing vulnerabilities without delay via security updates;
  3. Regular testing and security reviews;
  4. Public disclosure policies and coordinated vulnerability disclosure (CVD);
  5. Secure distribution of patches and security advisories.

# Responsible committee and deliverables

- **Technical Committee**: CEN-CLC/JTC 13 WG 9[^stan4cra-jtc13].
- **Deliverable**: `prEN 40000-1-3` (Work Item 81335 / 81344).
