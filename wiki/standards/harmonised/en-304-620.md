# Summary

EN 304 620 is an ETSI draft European Standard under Standardisation Request M/606 Line 20[^m606], defining essential cybersecurity requirements for products with digital elements providing virtual private network (VPN) functionality under CRA Annex III Class I point 5[^etsi-docbox-620].

# Legal effect

This document is an enquiry draft. It has **not** been cited in the OJEU and confers **no** presumption of conformity with Regulation (EU) 2024/2847.

# Applicability

Applies to:
- Standalone VPN client and server software;
- Dedicated VPN gateway appliances and hardware routers with built-in VPN servers;
- IPsec, WireGuard, and TLS-based VPN implementations.

# Requirements and high-level coverage

EN 304 620 addresses:
- Robust cryptographic protocol negotiation (IKEv2, WireGuard, TLS 1.3) and secure cipher suite enforcement;
- Mutual endpoint authentication (certificates, pre-shared keys with high entropy, MFA);
- Traffic encapsulation integrity, anti-replay mechanisms, and forward secrecy;
- Split-tunneling policy enforcement, kill-switch functionality, and DNS leak prevention;
- Secure management plane interfaces and administrative access controls.
