# Summary

EN 304 635 is an ETSI draft European Standard under Standardisation Request M/606 Line 35[^m606], defining essential cybersecurity requirements for virtualisation systems, hypervisors, and container runtimes categorized as Important Products Class II under CRA Annex III Class II point 1[^etsi-docbox-635].

# Legal effect

This document is an enquiry draft. It has **not** been cited in the OJEU and confers **no** presumption of conformity with Regulation (EU) 2024/2847. Products in Class II require third-party conformity assessment or full quality assurance modules under CRA Article 32.

# Applicability

Applies to:
- Type-1 (bare-metal) and Type-2 hypervisors (KVM, Xen, ESXi, Hyper-V);
- Container runtime environments (containerd, CRI-O, Docker Engine) and container orchestrator nodes;
- MicroVM and sandboxed virtualization runtimes (Firecracker, gVisor).

# Requirements and high-level coverage

EN 304 635 addresses:
- Robust virtual machine (VM) and container guest-to-host breakout defenses;
- CPU microarchitectural side-channel mitigations (Spectre, Meltdown, MDS, L1TF partition flushes);
- Mandatory container image cryptographic signature and provenance validation (Cosign, Notary);
- Kernel namespace and cgroup isolation hardening, seccomp filtering, and Linux capability drop enforcement;
- Virtual memory encryption (AMD SEV-SNP, Intel TDX) and confidential computing attestation support.
