# Summary

M/606 Line 32 requests a vertical European Standard establishing essential cybersecurity requirements for smart-home products with security functionalities (such as smart door locks, connected security cameras, baby monitoring cameras, alarm systems, and smart home gateways) under CRA Annex III Class I point 17[^m606].

# Legal effect

This request entry sets the standardisation mandate; presumption of conformity requires publication in the OJEU.

# Requested scope and mandate

- **Legal basis**: CRA Annex III, Class I, point 17.
- **Mandate objective**: Specify requirements for video stream end-to-end encryption, replay attack mitigation on lock actuators, tamper detection, secure local/remote video storage, and brute-force lockouts.

# Responsible committee and deliverables

- **Technical Committee**: ETSI TC CYBER / WG EUSR (Rapporteurs: Kilian Mitterweger, Gisela Meister, Davide Pratone)[^stan4cra-etsi].
- **Deliverable**: `EN 304-632` (ETSI Work Item `REN/CYBER-00117`, WKI ID 74417)[^etsi-wi-74417].
