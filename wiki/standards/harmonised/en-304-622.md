# Summary

EN 304 622 is an ETSI draft European Standard under Standardisation Request M/606 Line 22[^m606], defining essential cybersecurity requirements for Security Information and Event Management (SIEM) systems under CRA Annex III Class I point 7[^etsi-docbox-622].

# Legal effect

This document is an enquiry draft. It has **not** been cited in the OJEU and confers **no** presumption of conformity with Regulation (EU) 2024/2847.

# Applicability

Applies to:
- Standalone and distributed SIEM software packages;
- Security analytics and log aggregation appliances;
- Extended Detection and Response (XDR) core correlation backends.

# Requirements and high-level coverage

EN 304 622 addresses:
- Log ingestion pipeline security, transport encryption (mTLS, Syslog-TLS), and data source authentication;
- Cryptographic integrity protection of stored event records (append-only storage, WORM, cryptographic chaining);
- Granular query access control and audit logging of analyst search activities;
- Robust parser execution environments resilient against log injection and denial of service;
- System availability, fault tolerance, and secure patch management.
