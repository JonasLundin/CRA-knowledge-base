# Summary

Point 2 of Annex III Class I designates standalone and embedded web browsers as Important Products with Digital Elements (Class I), with technical scope detailed in Commission Implementing Regulation (EU) 2025/2392.[^cra-annex-3] [^reg-2025-2392]

# Legal effect

Browsers placed on the EU market must satisfy the conformity assessment procedures of Article 32(2) and meet rigorous sandbox, memory safety, and web origin isolation requirements under Annex I.[^cra-art-32]

# Applicability

Covers software applications whose primary purpose is to navigate, retrieve, parse, render, and execute content from web resources (e.g. HTML, CSS, JavaScript), including:
- Desktop and mobile standalone web browsers;
- Embedded web browser engines distributed as independent components for third-party application integration.[^reg-2025-2392]

# Requirements or coverage

- **Conformity assessment route:** Module A (with full application of cited harmonised standards) or third-party Module B+C / Module H (Article 32(2));[^cra-art-32]
- **Relevant vertical standards:** M/606 line 17 (ETSI EN 304-617);
- **Vulnerability reporting:** Mandatory 24h/72h reporting of actively exploited zero-day browser vulnerabilities via the SRP under Article 14.

# Dates and transitions

- Article 14 reporting applies from 11 September 2026.
- Full product conformity applies from 11 December 2027.
