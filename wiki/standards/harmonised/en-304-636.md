# Summary

EN 304 636 is an ETSI draft European Standard under Standardisation Request M/606 Line 36[^m606], establishing essential cybersecurity requirements for firewalls, intrusion detection systems (IDS), and intrusion prevention systems (IPS) under CRA Annex III Class II point 2[^etsi-docbox-636].

# Legal effect

This document is an enquiry draft. It has **not** been cited in the OJEU and confers **no** presumption of conformity with Regulation (EU) 2024/2847. Products in Class II are subject to third-party conformity assessment procedures under CRA Article 32.

# Applicability

Applies to:
- Network firewalls, Next-Generation Firewalls (NGFW), and Web Application Firewalls (WAF);
- Network-based and host-based Intrusion Detection/Prevention Systems (NIDS/NIPS/HIDS/HIPS);
- Dedicated packet inspection appliances and virtual security gateway VNFs.

# Requirements and high-level coverage

EN 304 636 addresses:
- Stateful inspection engine robustness and evasion attack countermeasures (packet fragmentation, TCP overlap handling, encoding bypasses);
- Cryptographic verification and secure distribution of threat intelligence, detection rules, and signature updates;
- Deep packet inspection (DPI) protocol parser hardening against remote code execution and Denial of Service;
- High-availability cluster synchronization, state table failover, and bypass-resistant fail-close architectures;
- Tamper-proof logging, audit trail integrity, and secure out-of-band management interfaces.
