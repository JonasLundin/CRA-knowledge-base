# Summary

M/606 Line 37 requests vertical European Standards establishing essential cybersecurity requirements for tamper-resistant microprocessors under CRA Annex III Class II point 3[^m606].

# Legal effect

This request entry sets the standardisation mandate; presumption of conformity requires publication in the OJEU. Products in Class II require third-party conformity assessment or an approved full quality assurance module under CRA Article 32.

# Requested scope and mandate

- **Legal basis**: CRA Annex III, Class II, point 3.
- **Mandate objective**: Define requirements for physical tamper resistance against high/enhanced-basic attack potential (fault injection, power analysis / DPA/SPA, physical probing, clock glitching), hardware crypto engines, and secure key enclaves.

# Responsible committee and deliverables

- **Technical Committee**: CLC/TC 47X WG 1 & WG 2[^stan4cra-clc47x].
