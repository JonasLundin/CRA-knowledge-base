# Summary

M/606 Line 34 requests a vertical European Standard establishing essential cybersecurity requirements for personal wearable products (such as smartwatches, health monitors, and fitness trackers) under CRA Annex III Class I point 19[^m606].

# Legal effect

This request entry sets the standardisation mandate; presumption of conformity requires publication in the OJEU.

# Requested scope and mandate

- **Legal basis**: CRA Annex III, Class I, point 19.
- **Mandate objective**: Define requirements for health and biometric data encryption, low-energy wireless link security (BLE pairing/bonding), location tracking privacy controls, and secure firmware updates.

# Responsible committee and deliverables

- **Technical Committee**: ETSI TC CYBER / WG EUSR (Rapporteurs: Kilian Mitterweger, Gisela Meister, Davide Pratone)[^stan4cra-etsi].
- **Deliverable**: `EN 304-634` (ETSI Work Item `REN/CYBER-00119`, WKI ID 74419)[^etsi-wi-74419].
