# Summary

M/606 Line 17 requests a vertical European Standard on essential cybersecurity requirements for standalone and embedded web browsers under CRA Annex III Class I point 2[^m606].

# Legal effect

This request line establishes the mandate; presumption of conformity requires publication of the harmonised standard reference in the OJEU.

# Requested scope and mandate

- **Legal basis**: CRA Annex III, Class I, point 2.
- **Mandate objective**: Specify requirements for renderer process sandboxing, origin isolation, extension security, secure certificate handling, safe browsing telemetry, and automated security patching.

# Responsible committee and deliverables

- **Technical Committee**: ETSI TC CYBER / WG EUSR (Rapporteur: Daniel Thompson-Yvetot)[^stan4cra-etsi].
- **Deliverable**: `EN 304-617` (ETSI Work Item `REN/CYBER-00108`, WKI ID 74408)[^etsi-wi-74408].
