# Summary

M/606 Line 22 requests a vertical European Standard establishing essential cybersecurity requirements for Security Information and Event Management (SIEM) systems under CRA Annex III Class I point 7[^m606].

# Legal effect

This request entry sets the standardisation mandate; presumption of conformity requires publication in the OJEU.

# Requested scope and mandate

- **Legal basis**: CRA Annex III, Class I, point 7.
- **Mandate objective**: Define requirements for secure log ingestion pipelines, integrity of archived event data, query access control, detection rule verification, and high availability.

# Responsible committee and deliverables

- **Technical Committees**:
  - ETSI TC CYBER / WG EUSR (Rapporteur: August Bournique) -> `EN 304-622` (ETSI WI `REN/CYBER-00113`, WKI ID 74413)[^etsi-wi-74413].
  - CLC/TC 65X WG 3 for industrial security monitoring platforms.
