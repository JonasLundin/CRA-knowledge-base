# Security Policy

This repository is consumed as agent context. False provenance, malicious links, hidden instructions, and release tampering are security issues.

Report suspected content poisoning, source impersonation, malicious links, exposed confidential information, or release-integrity problems through GitHub's private vulnerability reporting for this repository. Use a public correction issue for ordinary factual errors that do not expose sensitive information.

Do not include secrets, exploit details requiring embargo, personal data, or confidential evidence in a public issue.
