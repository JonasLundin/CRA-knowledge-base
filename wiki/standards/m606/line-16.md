# Summary

M/606 Line 16 requests vertical European Standards specifying essential cybersecurity requirements for identity management systems, privileged access management (PAM) software and hardware, and access control readers, including biometric readers[^m606].

# Legal effect

This request entry creates no direct presumption of conformity until standard adoption and OJEU citation.

# Requested scope and mandate

- **Legal basis**: CRA Annex III, Class I, point 1.
- **Mandate objective**: Define product-specific security requirements for authentication strength, credential lifecycle management, biometric template protection, and physical/logical access reader interfaces.

# Responsible committee and deliverables

- **Technical Committee**: CEN/TC 224 WG 17 (Protection Profiles in the context of SSCD / Secure Elements)[^stan4cra-tc224].
