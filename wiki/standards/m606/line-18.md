# Summary

M/606 Line 18 requests a vertical European Standard establishing essential cybersecurity requirements for password managers under CRA Annex III Class I point 3[^m606].

# Legal effect

This request entry sets the mandate; legal presumption of conformity requires citation in the OJEU.

# Requested scope and mandate

- **Legal basis**: CRA Annex III, Class I, point 3.
- **Mandate objective**: Specify requirements for master key derivation, zero-knowledge encryption architectures, local memory sanitisation, clipboard protection, secure synchronisation, and biometrics integration.

# Responsible committee and deliverables

- **Technical Committee**: ETSI TC CYBER / WG EUSR (Rapporteur: Daniel Thompson-Yvetot)[^stan4cra-etsi].
- **Deliverable**: `EN 304-618` (ETSI Work Item `REN/CYBER-00110`, WKI ID 74410)[^etsi-wi-74410].
