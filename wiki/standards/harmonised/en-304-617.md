# Summary

EN 304 617 is an ETSI draft European Standard developed in response to Standardisation Request M/606 Line 17[^m606]. It specifies product-specific essential cybersecurity requirements for standalone and embedded web browsers categorized under CRA Annex III Class I point 2[^etsi-docbox-617].

# Legal effect

This document is an enquiry draft. It has **not** been cited in the Official Journal of the European Union (OJEU) and does **not** confer presumption of conformity with Regulation (EU) 2024/2847.

# Applicability

Applies to:
- Standalone web browsers on desktop and mobile operating systems;
- Embedded browser runtimes (WebViews, embedded rendering engines) integrated into applications and consumer electronics.

# Requirements and high-level coverage

EN 304 617 addresses:
- Multi-process sandbox isolation between browser UI, network stack, and renderer processes;
- Same-origin policy enforcement and secure cookie handling;
- Browser extension isolation, permission gating, and manifest verification;
- TLS certificate verification and secure transport enforcement (HSTS);
- Rapid automated security update mechanisms and vulnerability patch deployment.
