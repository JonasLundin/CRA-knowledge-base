# Summary

M/606 Line 28 requests vertical European Standards establishing essential cybersecurity requirements for microprocessors and microcontrollers with security-related functionalities (non-tamper-resistant) under CRA Annex III Class I point 13[^m606].

# Legal effect

This request entry sets the standardisation mandate; presumption of conformity requires publication in the OJEU.

# Requested scope and mandate

- **Legal basis**: CRA Annex III, Class I, point 13.
- **Mandate objective**: Define requirements for hardware security primitives (true random number generators, cryptographic accelerators), secure bootROM verification, debug port lock-down (JTAG/SWD), and memory protection units (MPU/MMU).

# Responsible committee and deliverables

- **Technical Committee**: CLC/TC 47X WG 1 & WG 2 (Semiconductors and Trusted Chips Implementation; experts Guido Abate, Eve Atallah)[^stan4cra-clc47x].
