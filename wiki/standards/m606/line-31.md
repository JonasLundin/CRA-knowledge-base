# Summary

M/606 Line 31 requests a vertical European Standard establishing essential cybersecurity requirements for general-purpose virtual assistants embedded in smart-home products under CRA Annex III Class I point 16[^m606].

# Legal effect

This request entry sets the standardisation mandate; presumption of conformity requires publication in the OJEU.

# Requested scope and mandate

- **Legal basis**: CRA Annex III, Class I, point 16.
- **Mandate objective**: Define requirements for voice command spoofing protection, microphone/sensor privacy indicators, secure cloud API communications, local credential caching, and authentication for physical actuations (e.g., unlocking doors).

# Responsible committee and deliverables

- **Technical Committee**: ETSI TC CYBER / WG EUSR (Rapporteurs: Kilian Mitterweger, Gisela Meister, Davide Pratone)[^stan4cra-etsi].
- **Deliverable**: `EN 304-631` (ETSI Work Item `REN/CYBER-00120`, WKI ID 74420)[^etsi-wi-74420].
