# Summary

M/606 Line 36 requests a vertical European Standard establishing essential cybersecurity requirements for firewalls, intrusion detection systems (IDS), and intrusion prevention systems (IPS) under CRA Annex III Class II point 2[^m606].

# Legal effect

This request entry sets the standardisation mandate; presumption of conformity requires publication in the OJEU.

# Requested scope and mandate

- **Legal basis**: CRA Annex III, Class II, point 2 (Important products Class II).
- **Mandate objective**: Define requirements for stateful packet inspection, deep packet inspection robustness, anti-evasion techniques, rule signature verification, tamper-resistant logging, and industrial protocol parsing.

# Responsible committee and deliverables

- **Technical Committees**:
  - ETSI TC CYBER / WG EUSR (Rapporteur: Damir Samardzic) -> `EN 304-636` (ETSI WI `REN/CYBER-00127`, WKI ID 74859)[^etsi-wi-74859].
  - CLC/TC 65X WG 3 for industrial automation firewalls and OT inspection appliances.
