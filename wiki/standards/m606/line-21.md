# Summary

M/606 Line 21 requests a vertical European Standard establishing essential cybersecurity requirements for network management systems (NMS) under CRA Annex III Class I point 6[^m606].

# Legal effect

This request entry sets the mandate; presumption of conformity requires publication in the OJEU.

# Requested scope and mandate

- **Legal basis**: CRA Annex III, Class I, point 6.
- **Mandate objective**: Define requirements for secure management protocol enforcement (SNMPv3, NETCONF, RESTCONF), administrative access controls, configuration drift detection, and telemetry confidentiality.

# Responsible committee and deliverables

- **Technical Committees**:
  - ETSI TC CYBER / WG EUSR (Rapporteur: Santeri Toikka) -> `EN 304-621` (ETSI WI `REN/CYBER-00112`, WKI ID 74412)[^etsi-wi-74412].
  - CLC/TC 65X WG 3 for industrial network management systems.
