# Summary

M/606 Line 33 requests a vertical European Standard establishing essential cybersecurity requirements for internet-connected toys under CRA Annex III Class I point 18[^m606].

# Legal effect

This request entry sets the standardisation mandate; presumption of conformity requires publication in the OJEU.

# Requested scope and mandate

- **Legal basis**: CRA Annex III, Class I, point 18.
- **Mandate objective**: Define requirements for child privacy protection, unauthenticated Bluetooth/Wi-Fi connection prevention, secure pairing, strict microphone/camera access controls, and parental consent telemetry mechanisms.

# Responsible committee and deliverables

- **Technical Committee**: ETSI TC CYBER / WG EUSR (Rapporteurs: Kilian Mitterweger, Gisela Meister, Davide Pratone)[^stan4cra-etsi].
- **Deliverable**: `EN 304-633` (ETSI Work Item `REN/CYBER-00118`, WKI ID 74418)[^etsi-wi-74418].
