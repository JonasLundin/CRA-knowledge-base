# Summary

EN 304 623 is an ETSI draft European Standard under Standardisation Request M/606 Line 23[^m606], defining essential cybersecurity requirements for boot managers and bootloader software under CRA Annex III Class I point 8[^etsi-docbox-623].

# Legal effect

This document is an enquiry draft. It has **not** been cited in the OJEU and confers **no** presumption of conformity with Regulation (EU) 2024/2847.

# Applicability

Applies to:
- UEFI boot managers, GRUB, U-Boot, coreboot, and proprietary stage-2/stage-3 bootloaders;
- Boot configuration managers and hypervisor initialisation loaders.

# Requirements and high-level coverage

EN 304 623 addresses:
- Anchoring boot integrity in a hardware Root of Trust (TPM, secure enclave, fused public keys);
- Cryptographic verification of digital signatures on kernel images, initramfs, and boot parameters;
- Anti-rollback mechanisms preventing downgraded execution of older, vulnerable boot components;
- Physical and logical access protection on boot configuration interfaces;
- Measured boot capabilities extending measurements into Platform Configuration Registers (PCRs).
