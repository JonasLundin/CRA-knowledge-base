# Summary

EN 304 631 is an ETSI draft European Standard under Standardisation Request M/606 Line 31[^m606], defining essential cybersecurity requirements for general-purpose virtual assistants embedded in smart-home products under CRA Annex III Class I point 16[^etsi-docbox-631].

# Legal effect

This document is an enquiry draft. It has **not** been cited in the OJEU and confers **no** presumption of conformity with Regulation (EU) 2024/2847.

# Applicability

Applies to:
- Voice-activated smart speakers and display hubs;
- Smart-home appliances with embedded voice or conversational AI assistants;
- Local and hybrid voice processing edge devices.

# Requirements and high-level coverage

EN 304 631 addresses:
- Acoustic and ultrasound command spoofing mitigations;
- Physical/visual microphone mute indicators and hardware-level disconnects;
- Explicit secondary user authentication for security-sensitive operations (e.g., disarming alarms, unlocking doors);
- Encrypted cloud API communications with mutual TLS and credential rotation;
- Local audio buffer sanitisation and user voice data deletion capabilities.
