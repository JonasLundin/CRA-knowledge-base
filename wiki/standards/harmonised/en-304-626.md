# Summary

EN 304 626 is an ETSI draft European Standard under Standardisation Request M/606 Line 26[^m606], defining essential cybersecurity requirements for general-purpose operating systems under CRA Annex III Class I point 11[^etsi-docbox-626].

# Legal effect

This document is an enquiry draft. It has **not** been cited in the OJEU and confers **no** presumption of conformity with Regulation (EU) 2024/2847.

# Applicability

Applies to:
- General-purpose client and desktop operating systems;
- Server operating systems;
- Embedded and mobile operating system distributions.

# Requirements and high-level coverage

EN 304 626 addresses:
- Kernel memory safety and exploit mitigations (KASLR, SMEP/SMAP, Control Flow Integrity / CFI, W^X page permissions);
- Mandatory Access Control (MAC) frameworks (SELinux, AppArmor, LSM) and user-space privilege separation;
- Cryptographic package and update signature verification;
- Native cryptographic services and secure hardware key-vault abstraction;
- Robust vulnerability patch delivery mechanisms and kernel live-patching safety.
