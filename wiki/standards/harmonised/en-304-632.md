# Summary

EN 304 632 is an ETSI draft European Standard under Standardisation Request M/606 Line 32[^m606], establishing essential cybersecurity requirements for smart-home products with security functionalities under CRA Annex III Class I point 17[^etsi-docbox-632].

# Legal effect

This document is an enquiry draft. It has **not** been cited in the OJEU and confers **no** presumption of conformity with Regulation (EU) 2024/2847.

# Applicability

Applies to:
- Smart door locks, access keypads, and motorized gate controllers;
- Connected security cameras, video doorbells, and baby monitoring cameras;
- Intrusion alarm systems, perimeter sensors, and smart home security hubs.

# Requirements and high-level coverage

EN 304 632 addresses:
- Video and audio feed end-to-end encryption (SRTP, WebRTC DTLS-SRTP, TLS 1.3);
- Anti-replay and cryptographic challenge-response for actuator commands (unlock, disarm);
- Physical and magnetic tamper detection with rapid alert notifications;
- Secure pairing mechanisms with authenticated out-of-band key exchange (e.g. QR codes, NFC);
- Automatic security firmware updates with rollback prevention.
