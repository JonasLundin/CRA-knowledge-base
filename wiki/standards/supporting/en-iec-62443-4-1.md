# Summary

EN IEC 62443-4-1:2018 is an international and European standard specifying secure product development lifecycle (SDLC) process requirements for industrial automation and control system (IACS) products[^en-iec-62443-4-1]. It provides a comprehensive framework mapped to CRA Annex I essential requirements by ENISA[^enisa-mapping].

# Legal effect

Use of EN IEC 62443-4-1 is voluntary. As a supporting standard that has **not** been cited in the OJEU under Regulation (EU) 2024/2847, compliance with it does **not** by itself create a legal presumption of conformity under CRA Article 27.

# Applicability

Provides industry-standard development lifecycle guidance for manufacturers of industrial controllers, OT network appliances, embedded devices, and software components.

# Requirements and high-level coverage

EN IEC 62443-4-1 defines 8 practice areas:
1. Security management;
2. Specification of security requirements;
3. Secure by design principles;
4. Secure implementation;
5. Security verification and validation testing;
6. Management of security-related issues;
7. Security update management;
8. Security guidelines for end users.
