# Summary

EN 304 625 is an ETSI draft European Standard under Standardisation Request M/606 Line 25[^m606], specifying essential cybersecurity requirements for physical and virtual network interfaces under CRA Annex III Class I point 10[^etsi-docbox-625].

# Legal effect

This document is an enquiry draft. It has **not** been cited in the OJEU and confers **no** presumption of conformity with Regulation (EU) 2024/2847.

# Applicability

Applies to:
- Physical Network Interface Cards (NICs), SmartNICs, and DPUs;
- Virtual network interfaces (TUN/TAP, veth pairs, virtio-net, vSwitches);
- Network interface device drivers and firmware.

# Requirements and high-level coverage

EN 304 625 addresses:
- Direct Memory Access (DMA) attack mitigations via mandatory IOMMU enforcement;
- SmartNIC/DPU on-board firmware secure boot and cryptographically signed update mechanisms;
- Virtual interface cross-tenant packet leakage and MAC/VLAN spoofing prevention;
- Network packet ring-buffer overflow protection and hardware parser hardening;
- Secure management channels for NIC telemetry and out-of-band management (NC-SI, MCTP).
