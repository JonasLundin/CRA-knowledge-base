# Summary

EN 304 624 is an ETSI draft European Standard under Standardisation Request M/606 Line 24[^m606], defining essential cybersecurity requirements for public-key infrastructure (PKI) and digital certificate issuance software under CRA Annex III Class I point 9[^etsi-docbox-624].

# Legal effect

This document is an enquiry draft. It has **not** been cited in the OJEU and confers **no** presumption of conformity with Regulation (EU) 2024/2847.

# Applicability

Applies to:
- Certificate Authority (CA) server software and Registration Authority (RA) engines;
- Automated Certificate Management Environment (ACME) servers and CMP/EST protocol handlers;
- Key management and certificate lifecycle software.

# Requirements and high-level coverage

EN 304 624 addresses:
- Mandatory integration with certified Hardware Security Modules (HSMs) for CA private key operations;
- Multi-party authorization (m-of-n dual control) for sensitive administrative operations;
- Tamper-evident, cryptographically signed audit logging for all certificate issuance and revocation events;
- High-availability Certificate Revocation List (CRL) and Online Certificate Status Protocol (OCSP) responders;
- Robust certificate profile validation preventing unauthorized extension injection or domain impersonation.
