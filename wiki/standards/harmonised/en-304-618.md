# Summary

EN 304 618 is an ETSI draft European Standard developed in response to Standardisation Request M/606 Line 18[^m606]. It defines cybersecurity requirements for standalone, cloud-backed, and browser-integrated password management software under CRA Annex III Class I point 3[^etsi-docbox-618].

# Legal effect

This document is an enquiry draft. It is **not** cited in the OJEU and confers **no** presumption of conformity with Regulation (EU) 2024/2847.

# Applicability

Applies to:
- Standalone desktop and mobile password manager applications;
- Browser extensions providing credential vaulting and autofill;
- Operating system credential vaults.

# Requirements and high-level coverage

EN 304 618 addresses:
- Master password derivation functions (Argon2id, PBKDF2 with high iteration counts);
- End-to-end zero-knowledge client-side encryption of credential vaults;
- Sensitive data memory protection and sanitisation (zeroing buffers on lock/exit);
- Clipboard protection, auto-clear timeouts, and anti-keylogging mitigations;
- Secure multi-factor authentication (MFA) and biometric unlock integration.
