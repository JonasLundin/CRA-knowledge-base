# Summary

M/606 Line 25 requests a vertical European Standard establishing essential cybersecurity requirements for physical and virtual network interfaces under CRA Annex III Class I point 10[^m606].

# Legal effect

This request entry sets the standardisation mandate; presumption of conformity requires publication in the OJEU.

# Requested scope and mandate

- **Legal basis**: CRA Annex III, Class I, point 10.
- **Mandate objective**: Define requirements for network stack driver security, DMA protection, buffer overflow prevention, virtual interface isolation (SR-IOV, vSwitch), and interface authentication.

# Responsible committee and deliverables

- **Technical Committees**:
  - ETSI TC CYBER / WG EUSR (Rapporteur: Santeri Toikka) -> `EN 304-625` (ETSI WI `REN/CYBER-00128`, WKI ID 74860)[^etsi-wi-74860].
  - CLC/TC 65X WG 3 for industrial network interfaces.
