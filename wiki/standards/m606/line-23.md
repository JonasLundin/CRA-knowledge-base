# Summary

M/606 Line 23 requests a vertical European Standard establishing essential cybersecurity requirements for boot managers under CRA Annex III Class I point 8[^m606].

# Legal effect

This request entry sets the standardisation mandate; presumption of conformity requires publication in the OJEU.

# Requested scope and mandate

- **Legal basis**: CRA Annex III, Class I, point 8.
- **Mandate objective**: Define requirements for secure boot chain establishment, hardware root of trust integration, cryptographic signature verification of stage-2 bootloaders/kernels, anti-rollback mechanisms, and configuration lock-down.

# Responsible committee and deliverables

- **Technical Committee**: ETSI TC CYBER / WG EUSR (Rapporteur: Christian Horchert)[^stan4cra-etsi].
- **Deliverable**: `EN 304-623` (ETSI Work Item `REN/CYBER-00114`, WKI ID 74414)[^etsi-wi-74414].
