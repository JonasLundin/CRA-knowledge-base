# Summary

M/606 Line 30 requests vertical standardisation deliverables addressing cybersecurity requirements for connected smart-home systems and home automation hubs under CRA Annex III Class I point 15[^m606].

# Legal effect

This request entry sets the standardisation mandate; presumption of conformity requires publication in the OJEU.

# Requested scope and mandate

- **Legal basis**: CRA Annex III, Class I, point 15.
- **Mandate objective**: Define requirements for smart-home hub isolation, secure pairing mechanisms, local network protocol encryption (Matter/Zigbee/Z-Wave/Wi-Fi), and firmware integrity.

# Responsible committee and deliverables

- **Technical Committee**: ETSI TC CYBER / WG EUSR & CEN-CLC/JTC 13[^stan4cra-etsi].
